# 运算量瓶颈参考值

## 一、访存延迟

| 层级       | 延迟          |
| -------- | ----------- |
| 寄存器      | ~0.3 ns     |
| L1 命中    | ~1 ns       |
| L2 命中    | ~4 ns       |
| L3 命中    | ~15 ns      |
| DRAM     | ~80~100 ns  |
| NVMe 随机读 | ~20~100 µs  |
| SATA SSD | ~100~150 µs |
| HDD 随机   | ~5~10 ms    |

## 二、网络 RTT

| 场景              | RTT        |
| --------------- | ---------- |
| 同机（Unix socket） | 10~50 µs   |
| 同机房内网           | 0.1~0.5 ms |
| 同城跨机房           | 1~3 ms     |
| 异地跨城            | 30~50 ms   |
| 跨国              | 150~300 ms |

## 三、单机资源能力

**算力**

| 项        | 参考值                    |
| -------- | ---------------------- |
| 简单操作单核   | 1e8 ~ 1e9 /s           |
| 随机访存密集单核 | 1e7 ~ 1e8 /s           |
| 多核       | 乘核数，但受内存带宽/NUMA 限制，不线性 |

**内存**

| 项          | 参考值              |
| ---------- | ---------------- |
| 容量         | 按机器，几十 ~ 几百 GB   |
| 带宽（顺序）     | 20 ~ 100+ GB/s   |
| 单核随机访问有效带宽 | 几 GB/s（受 MLP 限制） |

**网卡**

| 网卡      | 带宽        | 小包 pps（理论） |
| ------- | --------- | ---------- |
| 1 GbE   | 125 MB/s  | ~148 万     |
| 10 GbE  | 1.25 GB/s | ~1488 万    |
| 25 GbE  | 3.1 GB/s  | ~3700 万    |
| 100 GbE | 12.5 GB/s | ~1.48 亿    |

**磁盘**

| 设备       | 顺序           | 随机 IOPS  |
| -------- | ------------ | -------- |
| HDD      | 100~200 MB/s | ~100~200 |
| SATA SSD | 500 MB/s     | 几万 ~ 十几万 |
| NVMe     | 2~7 GB/s     | 几十万 ~ 百万 |

## 四、中间件（单实例）

| 组件                 | 参考吞吐           | 瓶颈         |
| ------------------ | -------------- | ---------- |
| Redis（每条一次请求）      | ~10 万 ops/s    | 网络 RTT     |
| Redis（pipeline/批量） | 几十万 ~ 百万 ops/s | CPU        |
| Memcached          | ~10 万+ ops/s   | 网络         |
| MySQL 简单读          | 几千 ~ 几万 QPS    | 连接/锁       |
| MySQL 写（fsync）     | 几千 ~ 1 万 TPS   | fsync      |
| Kafka 单 broker     | 几十万 ~ 百万 msg/s | 磁盘顺序写      |
| Kafka 全集群          | 百万 ~ 千万 msg/s  | 分区分摊       |
| ES 单节点索引           | 几千 ~ 几万 docs/s | 索引+refresh |
| 典型 Web 服务单机        | 几千 ~ 几万 QPS    | 业务逻辑       |
