# 1. 计算机病毒与蠕虫
*   **计算机病毒 (Virus)**：
    *   **定义**：寄生在其他程序中，通过修改宿主程序来传播。
    *   **核心特征**：传染性（核心）、潜伏性、触发性、**寄生性**（必须依附宿主）、非授权性、破坏性。
    *   **结构**：
        1.  **引导模块**：初始化和加载。
        2.  **搜索模块**：寻找新宿主，决定扩散能力。
        3.  **感染模块**：核心，实现自我繁殖。
        4.  **表现模块**：执行最终破坏/显示。
        5.  **标识模块**：防止重复感染。
*   **计算机蠕虫 (Worm)**：
    *   **特征**：**独立性**（不依附程序）、**主动传播性**（利用漏洞自动扫描）、**网络依赖性**。
    *   **结构**：发现（搜索）、漏洞利用（攻击）、传输、负载（Payload）、控制模块。
*   **病毒 vs 蠕虫**：病毒靠宿主运行传播，蠕虫靠网络漏洞主动传播。

# 2. 远程控制木马 (RAT)
*   **组成**：
    *   **服务端 (Server)**：植入受害者的程序（被控端）。
    *   **客户端 (Client)**：攻击者使用的控制界面（控制端）。
*   **入侵步骤 (6 步)**：
    1.  **配置木马**：设置上线 IP/端口、安装路径、自启动、免杀等。
    2.  **传播木马**：通过软件捆绑（主）、邮件附件、挂马网页、社会工程学等。
    3.  **运行木马**：首次运行（欺骗/漏洞） $\rightarrow$ 持久化（注册表、服务、计划任务）。
    4.  **信息反馈 (上线)**：向攻击者回传 IP、系统版本、杀软信息等。
    5.  **建立连接**：正向或反向建立通信信道。
    6.  **远程控制**：实施窃密、文件操作、监控等。

# 3. 连接与隐藏技术
*   **反向连接 (Reverse Connection)**：
    *   **原理**：受害者服务端主动连接攻击者客户端。
    *   **优点**：解决**内网 IP**、**动态 IP** 问题，**绕过防火墙**（防火墙通常不限制向外发起的连接）。
*   **改进的反向连接**：通过中介服务器（如动态域名、社交媒体）获取攻击者当前 IP，增加隐蔽性。
*   **木马隐藏技术**：
    *   **存储隐藏**：文件名/图标伪装（如 `.docx.exe`）、修改文件属性（隐藏）、加壳加密、文件系统级 Rootkit。
    *   **加载隐藏**：自启动位置隐蔽（注册表深层）、DLL 劫持。
    *   **运行隐藏 (核心)**：
        1.  **进程隐藏**：Hook API 欺骗进程列表、**DLL 注入**（无独立进程）、利用 `Rundll32` 运行。
        2.  **通信隐藏**：**端口复用**（共用 80/443 端口）、**ICMP 潜伏**（无端口监听）、**反向连接**。

---

**复习重点**：
1.  **病毒与蠕虫的区别**（是否独立、是否主动、是否寄生）。
2.  **反向连接的必要性**（为什么正向连接不行？——防火墙与 NAT 限制）。
3.  **木马四大隐藏维度**：文件名、自启动、进程（DLL 注入）、通信（反向链接/ICMP）。
