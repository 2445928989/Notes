# 四种类型的网络扫描、不同扫描方法原理和优缺点

1. 主机扫描
   扫描识别目标主机的工作状态（开/关机）
2. 端口扫描
   识别目标主机端口的状态（监听/关闭）
3. 操作系统检测
   识别目标主机的操作系统类型
4. 漏洞扫描
   识别目标系统可能存在的漏洞

## 扫描方法

主机扫描
- **ARP 扫描**：优点：高效快速，可靠性高。缺点：无法路由
- **ICMP 探测**：
    - **ICMP Echo**：优点：简单直接，可跨越路由。缺点：不可靠
    - **ICMP Non-Echo**：Echo+绕过防火墙。
端口扫描
- **TCP 探测**：
    - **TCP SYN**：发送 SYN 包，收到 SYN/ACK 或 RST 均证明主机存活。
    - **TCP ACK Ping (-PA)**：发送 ACK 包，存活主机会回 RST。**优点：可穿越无状态防火墙**。
- **UDP 探测 (-PU)**：发送 UDP 包到高位端口，收到 ICMP 端口不可达证明存活。
