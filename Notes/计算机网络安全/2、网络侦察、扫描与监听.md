# 四种类型的网络扫描、不同扫描方法原理和优缺点

1. 主机扫描
   扫描识别目标主机的工作状态（开/关机）
2. 端口扫描
   识别目标主机端口的状态（监听/关闭）
3. 操作系统检测
   识别目标主机的操作系统类型
4. 漏洞扫描
   识别目标系统可能存在的漏洞

## 扫描方法

### 主机扫描技术

| 扫描类型        | 子类型           | 优点         | 缺点    |
| ----------- | ------------- | ---------- | ----- |
| **ARP 扫描**  | -             | 高效快速，可靠性高  | 无法路由  |
| **ICMP 探测** | ICMP Echo     | 简单直接，可跨越路由 | 不可靠   |
|             | ICMP Non-Echo | 可绕过部分防火墙   | 可靠性较低 |

### 端口扫描技术

#### TCP 扫描

| 扫描类型      | 技术名称        | 优点             | 缺点                                 |
| --------- | ----------- | -------------- | ---------------------------------- |
| **开放扫描**  | TCP Connect | 无需特殊权限、可靠性高    | 容易被检测、速度较慢                         |
| **半开放扫描** | SYN 扫描      | 隐蔽性强、速度快、适用性广  | 需要特殊权限、可能被检测、网络不稳定可能误报             |
| **隐蔽扫描**  | FIN 扫描      | 不会发起 TCP 连接，隐蔽 | 需要构造专门数据包、无法区分开放与被过滤、主要适用于 Unix 系统 |
|           | Xmas 扫描     | 同上             | 同上                                 |
|           | Null 扫描     | 同上             | 同上                                 |

#### UDP 扫描

| 扫描类型       | 优点        | 缺点      |
| ---------- | --------- | ------- |
| **UDP 扫描** | 能够探测UDP服务 | 速度慢、不可靠 |

# 交换式环境的网络流量劫持（端口镜像、MAC攻击、端口盗用、ARP欺骗）

1. **端口镜像 (Port Mirroring)**
    - **原理**：由网络管理员配置，将交换机一个或多个端口的数据流量复制（镜像）到指定的监控端口。
    - **用途**：通常用于合法的网络运维、安全审计和故障排查。

2. **MAC 攻击 / MAC 洪泛 (MAC Flooding)**
    - **原理**：攻击者发送大量伪造源 MAC 地址的数据帧，填满交换机的 **CAM 表**（MAC 地址表）。
    - **后果**：当 CAM 表耗尽后，交换机无法进行正常的单播转发，会退化为“集线器”模式，将所有数据帧**广播**到所有端口，从而允许攻击者监听。

3. **端口盗用 (Port Stealing)**
    - **原理**：攻击者不断发送源 MAC 地址为“受害者 MAC”的伪造帧。
    - **后果**：交换机会错误地学习到受害者的 MAC 地址位于攻击者所在的端口，从而将发往受害者的流量转发给攻击者。攻击者嗅探数据后需将其转发回受害者以维持通信。

4. **ARP 欺骗 (ARP Spoofing)**
    - **原理**：利用 ARP 协议无状态、无认证的缺陷，攻击者向局域网发送伪造的 ARP 响应包，将自己的 MAC 地址伪装成网关或其他主机的 MAC 地址。
    - **后果**：受害主机的 ARP 缓存被污染，原本发往网关或目标主机的数据包会被发送到攻击者主机，实现中间人监听。
