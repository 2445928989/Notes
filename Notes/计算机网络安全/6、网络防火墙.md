### 第6讲：网络防火墙核心总结

#### 1. 简单包过滤 vs. 状态检测包过滤 (核心原理)
*   **简单包过滤防火墙 (无状态)**：
    *   **工作机制**：孤立地检查每一个数据包的头部（IP、端口、协议）。
    *   **致命缺陷**：无法判断一个入站包是内部请求的**合法响应**，还是外部发起的**恶意攻击**。
    *   **配置难度**：必须显式配置双向规则（去和回），安全性低且繁琐。
*   **状态检测包过滤防火墙 (有状态)**：
    *   **工作机制**：在内存中维护一个“**连接状态表**”。第一个包匹配 ACL 规则后，后续包直接通过查询状态表快速转发。
    *   **优势**：能识别“响应包”，配置单向规则即可（自动放行回程流量）；性能极高（查表比匹配规则库快）。

#### 2. 防火墙作用、规则理解与配置 (应用实践)
*   **作用**：实施安全策略（门卫）、保护脆弱服务、内外隔离、监控与审计。
*   **规则匹配原则**：
    1.  **顺序匹配**：从上往下查。
    2.  **首次匹配生效**：一旦命中，不再看后续规则。
    3.  **具体在前，通用在后**：细化的 IP/端口规则放在全网段规则前面。
    4.  **默认规则**：通常采用“默认拒绝一切”，只开放必要的。
*   **规则表核心五元组**：`动作 (Action)`、`协议 (Protocol)`、`源IP/端口`、`目的IP/端口`。

#### 3. 防火墙体系结构/部署方式 (架构设计)
*   **屏蔽路由器**：最基础，由路由器 ACL 实现，安全性弱。
*   **双宿主机**：堡垒主机有两个网卡，彻底阻断路由，必须通过代理软件通信。
*   **屏蔽主机**：组合结构。路由器过滤异常包，剩下的全部导向内网的堡垒主机进行深度处理。
*   **屏蔽子网 (考试最高频)**：
    *   包含**外部路由器**、**内部路由器**和 **DMZ (非军事化区)**。
    *   **DMZ** 放置公开服务器（Web、Mail）。
    *   **双重防线**：即使外部路由器被攻破，内部路由器仍能保护内网核心数据。

#### 4. 不同类型防火墙的优缺点比对 (性能与安全)
| 类型       | 优点               | 缺点                        |
| :------- | :--------------- | :------------------------ |
| **包过滤**  | 速度最快、透明、成本低      | 不安全、无状态                   |
| **状态检测** | 性能与安全平衡、配置简化     | 无法分析应用层内容（如防不住 SQL 注入/木马） |
| **应用代理** | 安全性最高、能分析内容、隐藏拓扑 | 性能开销巨大（延迟高）、不透明           |
| **NGFW** | 全能型              | 价格昂贵、处理大流量时对硬件要求极高        |

**考试提醒**：如果题目考到“防火墙不能防范什么”，记得答“**内网攻击**”、“**病毒/木马内容**”以及“**绕过防火墙的非法连接**”。
